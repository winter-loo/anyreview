# Markdown 网页渲染改进方向

记录日期：2026-09-09。状态：待排期，尚未实施。

## 目标与参考项目

用户指定参考仓库：[markdown-viewer/markdown-viewer-extension](https://github.com/markdown-viewer/markdown-viewer-extension)。

未来改进 ReviewLoop 的 Markdown Web 阅读与评审体验，目标是达到与该项目相同或类似的渲染完整度、阅读布局和 UI 品质，同时保留 ReviewLoop 的标注与提交反馈能力。参考范围包括整个阅读页面，不仅是增加几个语法插件。

本次仅记录需求和参考资料，不代表已选定替换方案，也不代表以下问题已经修复。

## 用户反馈与优先级

以下是用户报告的问题，本次未逐项复现；实施时先收集触发问题的 Markdown 样例。

1. **TOC 目录链接不能跳转。** 优先排查标题锚点生成与目录链接是否匹配，覆盖中文、重复标题、标点和 URL 编码；点击后应定位到正确章节，且标题不被顶部固定栏遮挡。保留浏览器前进/后退和带 hash 的直达链接。
2. **数学公式无法显示。** 支持行内和独立公式，明确支持的 LaTeX 分隔符与语法；错误公式应有可理解的回退，手机端长公式不能造成整页横向溢出。
3. **其他图表支持不足。** 在已有 Mermaid 支持基础上，根据实际文档样例建立兼容清单，评估参考仓库覆盖的图表格式。不能将“已有 Mermaid”当作图表需求已经完成。
4. **整体阅读 UI 需要提升。** 对照参考项目实际页面，改进 TOC 导航、正文宽度、中文排版、标题层级、代码高亮、表格、图表展示及主题；同时验证桌面和手机布局。保留目前手机单行标题栏，以及有标注才出现的提交按钮和非零数字 badge。

## 已查阅的上游资料

2026-09-09 查阅上游 [README](https://github.com/markdown-viewer/markdown-viewer-extension#readme)：项目自称 docu.md Markdown Viewer，介绍了数学公式、代码高亮、文档主题，以及 Mermaid、PlantUML、Vega/Vega-Lite、drawio、Canvas、Infographic、Graphviz 等图表支持；也提供使用同一渲染能力的 Node.js HTML CLI。

这些是上游文档声明，不是本项目已验证或已实现的能力。后续需要运行上游 demo、阅读对应实现，并用相同样例做实际比较；本次没有完成 UI 对比或源码选型。

## 后续实施方式与验收

- 先用用户出问题的文档建立样例集，明确各项失败现象；优先修复 TOC 和公式，再推进图表与整体 UI。
- 使用同一份样例对比上游与 ReviewLoop，记录渲染差异及手机截图，形成可复用的回归检查。
- 重新评估现有渲染器增强、复用上游组件或更换渲染层等方式；实施前核对上游许可证和复用范围，不预先锁死某一种技术路线。
- 渲染与标注一起验收：选中文字、保存评论、刷新恢复、删除、提交给 AI，以及 `review feedback --json` 返回的原文和位置应保持正确。公式和图表改变 DOM 时，必须明确其标注方式，避免字符偏移错误。
- 长文档与多图表场景下检查首次阅读速度、滚动和按需加载；错误图表不能拖垮整篇文档。
- 浏览器扩展专属功能不是本次目标；重点是可在 ReviewLoop Web 页面内使用的渲染与阅读体验。
